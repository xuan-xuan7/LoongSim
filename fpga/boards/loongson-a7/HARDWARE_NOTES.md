# A7 实验箱资料核对

核对资料：用户提供的《实验箱A7-原理图.pdf》（FPGA-A7-PRJ-UDB V1.0，10 页）与
《引脚对应关系.xlsx》。原始文件保持不变；本目录只记录集成需要的事实与对应关系。

- 器件：XC7A200T、FBG676；速度等级 -1 根据龙芯配套 Vivado 教程确认。
- 系统时钟：AC19，100 MHz；默认时钟约束为 10 ns。
- 复位：Y3，按下为低电平，资料说明自带防抖。
- 单步按键：Y5 / V6，按下为低电平。
- 原理图第 8 页的 `J_JTAG` 是 2×7、2.00 mm 下载接口；第 5 页的 USB3500 是外设 USB PHY。
  FPGA JTAG 与 CPU EJTAG 也不是同一个接口。原理图未给出外接 USB/JTAG 下载器的具体型号。
- 原理图第 2 页的单色 LED 接 3.3 V，经电阻和 LED 接到 FPGA 引脚，为低电平点亮。
  映射到单色 LED 的输出由板卡接口自动反相，使电路信号 1 对应实体灯亮。学生不必为板卡另加非门。
- 双色 LED 的引脚名称 R/G 与实际点亮颜色相反，引脚表对此有明确说明。

## 保留既有资源 ID

现有 XDC 的总线位顺序与板级信号编号不完全相同。为兼容已有电路和映射，保留资源 ID，
通过 `verified-pins.csv` 明确列出资源、真实信号、封装引脚和引脚表单元格：

映射界面直接显示 SW7、SW6、LED16 等实物编号；括号形式的资源 ID 仅保留在工程数据中兼容旧映射。

- `led[0]` 是 `FPGA_LED16` / K23，`led[15]` 是 `FPGA_LED1` / H7。
- `switch[0]` 是 `FPGA_SW7` / Y6，`switch[7]` 是 `FPGA_SW0` / AC21。
- `num_csn[7]` 是 `FPGA_NUM_CSN0` / D3。
- `num_a_g[6:0]` 依次是 a 至 g；`num_a_g[0]` 为 g 段。

## 映射界面的实物位置

以照片的板卡朝向为准（LCD 在右、拨码开关在下），位置来自用户引脚表的描述列：

- 拨码开关工作表 C4 / C11：从左到右为 SW0～SW7；`switch[7]` 位于最左，`switch[0]` 位于最右。
- LED 灯工作表 C4 / C5：LED1 从最左开始，其余依次排列至 LED16。
  C19 仍写“左起第八个”，与16灯实物及连续编号矛盾，不按此处笔误改变编号。
- 八段数码管工作表 C4 / C11：从左到右为数码管0～7。
- 单步调试按键工作表 C4 / C5：按钮0在下、按钮1在上。
- 4X4矩阵键盘工作表 C4～C8：列从左到右、行从上到下；ROW3/ROW4描述重复“第二行”的笔误
  以原理图中的 ROW1～ROW4 顺序和4×4排列纠正。

界面以单个红框和文字提示显示以上位置，不改变资源 ID、FPGA引脚或逻辑电平。
矩阵键盘区域叠加4×4编号示意：清理过标记的照片不能用作器件数量或电气连接的依据。

原模板中的 `num_data[31:0]` 与资料中的 LCD 接口不对应，暂不在映射工具中提供。
完整模板保留，后续应按 LCD 实际控制信号和数据总线重新定义。

使用已安装 openpyxl 的 Python 环境可重复核对（只读原表）：

```powershell
python toolchain/verify-a7-pins.py '引脚对应关系.xlsx'
```

配套教程：[Vivado 使用入门](https://bookdown.org/loongson/_book3/appendix-vivado-startup.html)。

## 实机核对（2026-10-29）

下载器为 Xilinx 协议 USB 下载器，冷启动及运行后均保留 `03fd:0007`；WinUSB 驱动。
加载本机配套 `xusbdfwu.hex` 后，读回单个 XC7A200T，IDCODE `0x03636093`。
LoongSim 已完成 SRAM 下载，INIT/DONE 均为 1；用户确认 SW0 / AC21 可以通过非门控制
LED1 / H7 亮灭。USB 拔插后的固件自动初始化也已纳入软件流程。
