# 开始使用 LoongSim

## 安装与启动

1. 打开 [GitHub Releases](https://github.com/xuan-xuan7/LoongSim/releases)，选择需要的版本。
2. Windows 用户下载名称以 `setup-unsigned.exe` 结尾的 EXE 安装向导，双击安装。
3. 安装完成后，从桌面或开始菜单启动 LoongSim。Windows 安装包内置 Java，无需单独安装。

当前完整版为1.1.0，支持 Windows 10/11 x64；1.0.1-logisim-only 仅提供电路编辑和仿真。
升级前保存自己的 `.circ` 电路文件，并关闭旧版程序。各版本的升级条件和签名情况见[版本记录](changelog/README.md)。

## 设计与仿真

新建或打开电路，放置输入、输出和逻辑组件，连接线路后检查仿真结果。
可通过“文件”菜单保存为 `.circ` 文件；元件标签和电路名称支持中文。

## 在实验箱上运行

当前 Windows FPGA 功能针对龙芯 A7 实验箱：XC7A200T、FBG676、速度等级-1。
给实验箱供电、连接 USB/JTAG 下载器并准备匹配的驱动。下载器需要初始化时，还需配套厂商固件；安装包不分发这些固件。

点击主界面“FPGA 实现”，依次完成：

1. **端口映射**：为电路的输入和输出端口，指定要映射的实验箱资源。
2. **生成位流**：完成综合、布局布线和比特流生成。
3. **下载到 FPGA**：检查设备，把生成的比特流下载到 FPGA 的临时配置区，断电后清除。

修改电路后应重新完成映射和位流生成，不能继续下载旧位流。
映射时可查看开关、LED 等资源的位置；普通多位端口可拆开逐位分配。
数码管支持七段段选和4位十六进制数值，矩阵键盘按具体按键映射。

门窗报警电路已完成实机验证；新增数码管、矩阵键盘适配的验证范围见[1.1.0记录](changelog/1.1.0.md)。
需要工具版本、日志、映射规则或排错资料时，查看 [Windows FPGA 集成](development/windows-fpga.md)及[端口映射说明](development/fpga-backend.md)。
