# LoongSim 1.1.0

首次发布日期：2026-11-02；安装包更新：2026-11-03。分支：`master`。平台：Windows x64。

[下载 Release](https://github.com/xuan-xuan7/LoongSim/releases/tag/v1.1.0)

## 2026-11-03 同版本更新

- **手动更新**：“帮助 → 检查更新”可查看新版本及说明，Windows x64 支持安装包下载、进度、取消与 SHA-256 校验；下载完成后保存电路并关闭软件，再手动安装。仓库公开发布后才可匿名检查更新；同版本替换不触发新版本提示。
- **电路导出与逻辑修复**：修正中文子电路导出、译码器和多路分配器的信号名、减法器位宽扩展、移位器选择位，以及 T／J-K／S-R 触发器反馈状态。
- **提前提示限制**：RAM、SimpleCounter 仍未实现当前 FPGA 导出；A7 布局布线工具不支持高／低电平锁存模式。现在导出前提示具体组件与位置。
- **安装包精简**：排除其他 FPGA 专用工具、数据库，以及当前 A7 流程未调用的独立工具；保留内置 Java、Python、共用库和许可证。EXE 从初版约516 MiB 缩至约274 MiB，安装目录约1.08 GiB。
- **验证**：新增组件参考向量、实际电路导出及综合网表对比、乱序逐位映射、真实位流生成和更新功能测试。范围与限制见[测试记录](../testing/2026-11-03.md)及[更新说明](../development/updates.md)。
- **同版本安装**：应用和 Release 仍为1.1.0，EXE 安装器内部修订号为1.1.0.1，并支持替换同版本 MSI。先保存电路并关闭所有 LoongSim 窗口；若旧安装器仍要求维护或卸载，请卸载旧版后安装，保留自己的 `.circ` 文件。

下面保留首次1.1.0发布的主要功能。当前 Release 的源码标签随本次安装包更新，初版对应提交为 `574b78b3155c5a421a7d5e9ba2361f3f54b2fa1c`，构建清单记录新版安装包对应的准确提交。

## 首次发布的主要功能

- Windows x64 接入 LoongSim 私有 FPGA 工具：Yosys/ABC、openXC7 布局布线与位流工具、XC7A200T 数据库、Python 和 openFPGALoader；锁定配套版本并校验 SHA256。
- 从“FPGA 实现”进入工作台，依次完成端口映射、生成位流并下载；综合和布局布线在生成位流时自动完成。
- 增加自动下载器识别、目标芯片检查、日志和生成结果校验；重新生成或修改工程后不能下载旧位流。下载使用 SRAM，不写入 Flash。
- 修复真实工具验证暴露的 Yosys 顶层传参和时钟封装语法问题；适配 openXC7 XDC，保留 100 MHz 时钟目标。
- 按原理图和引脚表核对 55 个资源引脚；保留总线 ID，记录与板级编号的对应关系，暂不开放未经资料验证的旧 LCD 数据总线。
- **端口名称与位置**：映射窗口保留电路中的中文标签；资源分两级选择，显示 SW0～SW7 等实物名称、左起位置和单个资源红框，不再要求辨认内部总线编号。
- **多位端口**：可以拆分后逐位分配到开关或 LED，保留每位原始标签，并检查缺失、重复占用和输入输出方向。
- **数码管**：保留 a～g 独立段选及7位整组段选，同时提供4位数值的0～F显示；显示位置由界面选择，LoongSim 处理选位与刷新。
- **矩阵键盘**：提供4×4具体按键，按下为1、松开为0；后台扫描、防抖并抑制有歧义的矩形串键组合。矩阵区使用明确的4×4位置示意。
- **图标与启动界面**：主窗口、FPGA窗口、启动画面和 Windows 安装启动器统一使用 LoongSim 龙芯图标。
- **仿真与实物一致性**：修复单色 LED 低电平适配，已在实验箱上确认门窗报警电路的开关组合符合仿真逻辑。
- **验证**：自动化测试、真实 Windows 综合和位流生成通过；段选128种组合、0～F、16个矩阵按键、防抖、120种双键组合及串键抑制通过仿真。新增数码管和矩阵键盘适配尚未完成实物显示/按键验证。
- **安装包**：Windows x64 EXE 安装包内置 Java 与完整 FPGA 工具链，安装后通过桌面或开始菜单运行。版本统一为1.1.0，本次仍为未签名包。

此版本来自 `master`，包含 FPGA 全流程。项目现已统一基于 master；原纯电路分支及其 Release 已退役，见[2026-11-03维护记录](2026-11-03-master-only.md)。
升级前保存电路并关闭旧版程序。实验箱下载仍需相应 USB 驱动和配套下载器初始化文件，说明见
[Windows FPGA 集成](../development/windows-fpga.md)。
## 安装与下载条件

- 下载 Release 中名称以 `setup-unsigned.exe` 结尾的安装向导，双击安装后从桌面或开始菜单启动。
- 已内置 Java 和 FPGA 工具，无需另外安装 Java、Python 或 WSL。适用 Windows 10/11 x64。
- 当前更新包约274 MiB，安装后目录约1.08 GiB；初版分别约516 MiB、3.35 GiB。安装时另需临时解压空间。
- USB/JTAG 下载需要匹配的 Windows 驱动；下载器需要初始化时，还需配套厂商固件。安装包不安装驱动、不分发厂商固件。
- 本版未签名。升级前保存电路并关闭旧版程序。FPGA 下载到临时配置区，实验箱断电后清除。

精简、组件修复与检查更新功能已纳入本次1.1.0安装包替换。
