# LoongSim 1.2.0

2026-11-23 · master · Windows 10/11 x64

[下载安装包](https://github.com/xuan-xuan7/LoongSim/releases/tag/v1.2.0)

## 本次改动

- **RAM 与教学计数器**。支持为龙芯 A7 实验箱生成位流。RAM 使用独立数据总线与边沿触发，输出使能留空或接高电平。教学计数器的 Max 端口可留空或连接常量。
- **十六进制数码显示**。4 位数码显示组件可以直接映射到实验箱数码管。七段数码管仍按 7 位段信号映射。
- **下载器兼容性**。LoongSim 识别支持的 Digilent 与 Xilinx 下载器。EXE 安装向导包含原版签名 FTDI 驱动。部分 Xilinx 下载器需准备 WinUSB 驱动和对应的厂商固件。

## 从旧版更新

在带有更新功能的 1.1.0 中选择 **帮助 → 检查更新 → 下载安装包**。校验完成后保存电路、关闭 LoongSim，然后双击下载的 EXE。也可以直接在发布页下载。安装包未进行代码签名。

FPGA 测试范围和工具配置见 [Windows FPGA 集成](../development/windows-fpga.md)。
