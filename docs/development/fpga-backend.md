# LoongSim FPGA 后端

仓库的 `fpga/` 目录保存 LoongSim 使用的 FPGA 编译运行时和板卡资源，第三方源码获取与分发义务按各自许可证处理。

| 目录 | 作用 |
|---|---|
| `yosys-runtime/` | 固定的 LoongArch Yosys 0.8、Berkeley ABC 和 Yosys 技术库 |
| `boards/loongson-a7/` | xc7a200tfbg676-1 的 XDC 模板、核对资料及引脚记录 |
| `runtime/windows-x64/` | Windows 私有完整工具、动态库与数据库（由锁定发行包安装，不提交 Git） |

第三方工具在构建机上单独编译，完成后只把对应运行时目录复制到这里。LoongSim 自己的流程
编排代码在 `logisim/`，板卡清单在 `fpga/boards/`，工具脚本在 `toolchain/`，详细说明在 `docs/`。

LoongArch 平台的 LoongSim 界面接通三个阶段：生成 Verilog 工程、端口映射并生成 XDC、调用 `yosys-runtime` 的
`synth_xilinx` 综合。运行时同时包含 `berkeley-abc`，`yosys-abc` 是指向它的符号链接。
Windows 平台通过单独的私有运行时继续完成布局布线和位流生成，并提供设备下载入口。

流程顺序为：生成 Verilog → 端口映射确认 → 生成本电路 XDC → Yosys 综合 → 后续布局布线和位流生成。
当前 Yosys 只读取 Verilog；XDC 会由后续 Xilinx 实现工具读取。先生成 Verilog 再生成 XDC，
是为了准确筛选当前电路真正存在的端口，并不表示 XDC 可以延迟到布局布线之后。

`yosys-runtime/usr/bin/yosys` 是 LoongArch ELF，仅供 LoongArch Linux 使用。
Windows 使用 `runtime/windows-x64/` 中的原生工具，工作台已接通综合、布局布线、位流生成和
设备下载入口；macOS 暂未接入。详见 [Windows 集成说明](windows-fpga.md)。

导出电路时，LoongSim 会把 `fpga/boards/` 中的板卡 XDC 作为完整模板复制到电路工程。
顶层 Verilog 端口映射确认后，LoongSim 才会生成独立的 `constraints.xdc`。`mapping.json` 的 `portMappings` 使用“电路端口 -> 板卡资源”方向，
会记录板卡全部资源、已经匹配的端口和未匹配端口。资源选择受输入/输出方向、位宽和重复占用规则限制。

映射窗口以已核对引脚的板卡资源为准，列表编号与照片上的资源区域对应；从列表选择资源时，
对应区域会高亮。照片只作位置参考，不提供悬停提示或点击映射。系统时钟单独列出，
由于照片中无法确认其位置，不在图上标点。未映射提示使用红色粗体，并显示剩余端口数。

端口列表和提示显示电路中填写的原始标签，包括中文；Verilog、XDC 和内部映射继续使用合法的 HDL 名称。
导出时生成 `port-labels.json` 保存两者的对应关系，合并的 I/O 总线还记录每一位所属的组件标签，
子电路内的组件带有原始实例标签路径。映射列表中将鼠标移到总线端口上，可以查看各位对应的标签。

资源选择分为两级：先选“拨码开关”“按钮”“LED”“数码管”等类别，再选择具体资源。
鼠标移到资源或通过键盘聚焦资源时，板卡图用红框突出单个位置，同时显示“左起第几个”等提示；
选定映射后保留该位置，切换电路端口时显示已有映射的位置。SW0在最左、SW7在最右，
数码管0在最左；这些位置以图中板卡朝向为准，来自配套引脚表，和内部 HDL 总线位序无关。
界面不再提供总线资源或数码管位选映射；旧映射文件中的总线资源 ID 保留兼容。

选中普通多位端口后，可以点击“拆分映射（逐位分配）”，分别为每一位选择同方向、1 位的资源，
例如把两个 4 位输入分别分配到 SW0～SW3、SW4～SW7。每一项会显示已分配的资源；缺少任何一位
都不能完成映射，同一个实体资源也不能重复占用。仍可保留整组映射；恢复整组时，无法合并的逐位分配会清除。
生成的 Verilog 保留原有总线，XDC 精确约束每一位，单色 LED 的低电平适配也按位处理。

“数码管”中先选择板卡编号 0～7，再选择接收信号的方式：

- 七段段选：1 位输出分别映射到 a～g（1 亮、0 灭），也可连接整组 7 位段选。
  每个段独立分配，同一显示位置未连接的段保持熄灭；界面附有 a～g 的位置示意图。
  七段显示组件按 `Segment_A`～`Segment_G` 匹配板卡段序；普通 7 位输出按 bit6=a、bit0=g，
  也可拆分后自行选择各位对应的段。此方式保留电路给出的亮灭信号，不添加数字译码。
- 16进制数值：4 位输出显示为 0～F，LoongSim 在适配电路中加入译码。
  电路中已有的“16进制数码显示”组件仍保留自身译码，其导出的七段信号使用七段段选方式连接。

两种方式都由 LoongSim 自动连接选位和
100 MHz 刷新时钟；多个显示组件共享段选并轮流刷新，无需学生绘制选位、扫描电路。
同一显示位置不能同时使用4位译码、整组段选与独立段选中的不同方式；不同位置可以混合使用。
显示组件中的小数点目前不连接。和普通 LED 合并导出的显示信号会按组件标签拆分，原电路 HDL 保持不变。
矩阵键盘按实物排列提供4×4个按键（第1行第1列至第4行第4列），分别映射到1位输入，
多位输入也可以拆分后逐位映射。按下对应输入为1，松开为0；原始行/列不再出现在资源选择中，
旧的行列资源 ID 保留兼容，但不能与自动按键扫描混用。
LoongSim 自动连接8个行列引脚，使用板载100 MHz时钟扫描（每列1 ms），对连续5个一致的完整扫描帧
进行防抖确认，约16～24 ms后更新按键状态。列线仅输出低电平或高阻态，行线同步后读取；
扫描器与数码管刷新共用同一个板载时钟。无二极管的矩形多键组合无法可靠区分，检测到这种歧义时
按无键处理并通过同样的防抖确认，避免向电路输出虚假按键。实际按键和同时按压效果仍需上板验证。

导出工程还会生成 `top-module.txt`、`sources.list` 和 `loongsim-project.json`。后续综合必须使用
`sources.list` 中的源文件和 `top-module.txt` 中的顶层，不能把工程目录里的临时 Verilog 文件混入。
`constraints.xdc` 中的每一个端口引用都会在代码层校验为该顶层真实存在的端口；总线通配符会按学生选择的
整条总线或单个 bit 展开，避免约束仍指向板卡模板中的原始名称。

使用 Logisim `Clock` 时，LoongSim 会额外生成 `loongsim-clock-support.v` 和 `*_LoongSimTop` 顶层封装。
封装把板卡 `FPGA_GlobalClock` 输入转换为 Logisim 的 5 位时钟树；XDC 针对封装顶层生成，内部的
`LOGISIM_CLOCK_TREE_*` 不会出现在学生的资源选择列表中。映射窗口不会允许时钟输入连接到拨码开关或普通按键。

Yosys 阶段会严格读取 `sources.list`，并确认 `top-module.txt` 对应的 Verilog 文件就在清单中；不能通过
手动修改清单来综合一个缺少顶层的工程。

工程目录由用户在 FPGA 工作台点击“1. 端口映射”时选择，不再自动创建到默认工作区的项目名子目录。
